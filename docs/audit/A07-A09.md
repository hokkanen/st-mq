# A07, A09, A01-011 and B12-013 disposition

This work uses the current native schema and contracts. Only the two permitted
v0.7.5 CSV formats retain their original historical interpretation; there are no
native database migrations or interpreters for old development state. No installed
equipment, household database, provider credentials or live commands were used.

## Decisions retained after review

* A timing comparison remains a timing benchmark, not causal controller savings or
  a claim that every alternative charging/heating schedule was feasible. Energy,
  cost and included time are never extrapolated through missing history.
* Interval-total energy remains uniformly allocated inside its original interval
  when splitting prices. The supplied total cannot identify the true subinterval
  power/price covariance; no invented accuracy bound or extra history was added.
* Whole Finnish days retain true 23/25-hour DST durations. Dated tariff facts,
  negative prices, labelled nearest-rate assumptions, weighted session diagnostics,
  routed heat-pump estimates and incomplete-cycle exclusions remain intact.
* Firewood benefit stays a retrospective paired-model scenario under the current
  corrected model. It is not frozen foreknowledge, a confidence interval or a
  certificate of electrical displacement. Stored observations are not recalibrated
  by meter/session diagnostics.
* No withdrawal is inferred from an incomplete market response. ENTSO-E's
  [Publication document schema, Table 3](https://www.entsoe.eu/Documents/EDI/Library/cim_based/schema/Publication_document_UML_model_and_schema_v1.3.pdf)
  identifies document ID, revision and creation time separately, but explicitly
  leaves business-process rules to implementation guides. This supports retaining
  those fields; it does not establish A44 withdrawal completeness. The code preserves
  the existing adapter's same-document revision contract and records partial absence
  without manufacturing deletions. A real sanitized A44 withdrawal sequence remains
  additional evidence, not a reason to guess its meaning.
* Current chart extensions, bounded latest-event lists, source timestamps, scalar
  boundary interpolation and viewport cancellation are retained. Display reduction
  is not a lossless export. Exact cubic clipping, physical touch/DeX/fullscreen and
  exhaustive accessibility behavior are not newly certified by these fixtures.
