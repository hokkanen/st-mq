# Pre-v1.0.0 compatibility disposition

The owner's policy is binding in `AGENTS.md` and
`docs/reconstruction-and-versioning.md`. Only read-only import of v0.7.5
`easee.csv` and `st-mq.csv` is retained. Accepted source rows are normalized at
that boundary. A future package-version edit does not begin production support;
that decision belongs to the actual v1.0.0 release.

The supplied B12 policy acceptance file passed all 23 checks. Those checks are
sentinels, not proof of completeness; current producer/consumer/configuration/UI
tests, recovery tests, browser and container checks provide additional evidence.
The original baseline passed 2,753 tests before changes. Retired-contract tests
were deliberately replaced or removed, so final suite counts are not directly
comparable to that baseline.

No development database was deleted or migrated. Selecting a fresh database and
re-importing permitted CSVs is an explicit operational step for the owner. No
mixed-ST-MQ-version support was added. Same-schema backup, restart, recovery,
transactional publication, SSH mirror mode and actively recorded
`legacyOutstanding` obligations were retained.
