audits, under the pre-v1.0.0 policy in `AGENTS.md`. All verification used synthetic

## Compatibility removals and adjacent callback fix

* **B12-010:** Removed the coarse learner implementation, `learning_samples`
  consumers, fallback checkpoint reconstruction, coarse history cursor/checkpoint,
  dead online worker and legacy controller entrypoint. The storage owner removed
  the table/API from the fresh schema. Current quality/comfort-reference helpers
  and the current `dhwrEligible` rule remain in small dedicated modules. Native

* **B12-011:** Writers/readers require one current sensor/input-segment contract.
  Removed old algorithm whitelists, `intervalInputs`/`thermal` decoders and redundant
  compatibility summaries. Charts refuse unsupported records. Merge validation is
  coordinated with the storage/recovery owner. Missing values within the current
  contract remain missing. Synthetic test fixtures now construct current records;
  they do not add a production compatibility reader.
* **B12-015:** Replaced obsolete controller/coarse-storage upgrade tests with
  current reconstruction, native-format rejection and focused DHWR rule tests.
  Tests of current safety, correction replay and crash publication were retained.
* **A11-003 (worker callbacks):** Background history-worker message/error reporting
  cannot throw if the database event writer fails. The fallback is one bounded,
  fixed, redacted stderr message; stderr failure is also caught.
  `history-worker-errors.test.js` injects both failures and secret-bearing worker
  errors and checks that callbacks neither throw nor expose those values.

## Deliberate unchanged outcomes and limitations

The paired native-reference cost comparison, terminal thermal-deficit charge,
bounded trial/search policies, frozen cycle assessments, native readback gating,
current `legacyOutstanding` restoration obligation and floor lease protocol are
retained. They serve current behavior or physical restoration, not development
format compatibility. The independent native and circulation recovery duties
must not be removed merely because an earlier comment called them legacy.

Pooled thermal states, fixed slow-state priors, manufacturer heat/electrical maps,
correlated burn tails and rolling holdout reuse remain documented modelling
limitations. The changes do not claim measured hydraulic flow, installed COP,
causal savings, independent burn experiments or statistical coverage probabilities.
Hardware commissioning remains an external installation prerequisite: tests do
not establish installed register scaling, relay polarity, native timer firmware
behavior, valve movement or an independent maximum-on safeguard. No automatic
commissioning flag or speculative new hardware model was introduced.
